# INFRAVENZ Fútbol — Sistema web Futsal (Python)
Requiere Python 3.9 o superior. No hay que instalar paquetes.

    python server.py        →  http://localhost:3000

- Modo demostración: entra con `admin@clases.edu.sv` (comisión) o cualquier otro `@clases.edu.sv` (estudiante).
- Login real con Google: define GOOGLE_CLIENT_ID y ADMIN_EMAILS antes de ejecutar.
- Estructura: database/ · models/ · services/ (puntos, sanciones, clasificación) · controllers/ · views/
